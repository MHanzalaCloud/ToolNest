# ⚡ ToolNest // High-Velocity Client-Side Utilities

> **Privacy-First, Zero-Latency Browser Utility Suite**  
> Run high-performance file transformations, conversions, and calculations 100% inside your local execution stack. Files never touch an external server.

---

## 🚀 Key Features

* **🔒 100% Client-Side Privacy:** All operations execute locally in your browser's WebAssembly and JavaScript memory. Zero file uploads or remote API reliance.
* **⚡ Zero Server Delay:** Instantaneous processing leveraging local hardware resources.
* **🛡️ Zero Tracking:** No user registration, telemetry, analytics, or cookies.
* **🎨 Cyberpunk / Digital Abyss UI:** Designed with high-contrast Laser Cyan (`#00F0FF`), Blaze Orange (`#FF5500`), and Matrix Lime (`#00FF66`) accents.

---

## 🛠️ Included Utilities

| Category | Route | Capabilities |
| :--- | :--- | :--- |
| **PDF Suite** | `/pdf/merge` | Client-side merging, splitting, and re-ordering using `pdf-lib` |
| **Image Tools** | `/image/resize` | Local compression, scaling, and WebP/PNG/JPEG conversion |
| **Calculators** | `/calculator/basic` | Developer, financial, and scientific calculation tools |
| **Converters** | `/converter/unit` | Instant unit, data byte, and numeric format conversions |
